# Agent 行为评测规则

## 目录职责

- `cases/`: 固定任务、输入、期望和标签。
- `fixtures/`: 评测仓库、样本数据和可复现环境。
- `evaluators/`: 确定性评分器、轨迹评分器和报告逻辑。

## 用例规范

- 用例 ID 保持稳定，格式为 `<domain>-<scenario>-<number>`。
- 每个用例声明目标、输入、环境、允许能力、成功条件和失败条件。
- 用例覆盖正常任务、边界输入、工具错误、预算终止和越权请求。
- fixture 具有明确来源、版本和重置方式。
- 真实模型评测记录模型、参数、提示版本、运行时间和重复次数。

## 评分与报告

- 优先使用确定性 evaluator，再为开放输出加入人工或模型评分。
- 行为变化比较任务成功率、工具参数正确率、步骤、token、费用、延迟和越权次数。
- 统计性指标附带样本数、重复次数和波动范围。
- 失败报告保留用例 ID、输入、预期、实际结果、关键事件和可复现命令。
- 原始大模型输出进入本地 artifact，版本库保存必要摘要和可比较结果。

## 变更规则

- 修复评测失败时保留原用例身份，保证前后结果可比较。
- 修改 prompt、工具描述、上下文策略或模型适配器时运行受影响评测集。
- 发布里程碑前运行固定回归集，并将结论写入 `verification/code/`。
