# Python 产品代码规则

## 包职责

- `agent_harness/core/`: 内部领域类型、事件、运行状态、Agent Loop 和预算。
- `agent_harness/providers/`: 模型提供商适配器和内部类型转换。
- `agent_harness/tools/`: 工具协议、注册表、参数 schema 和内置工具。
- `agent_harness/policy/`: 能力标签、风险分级、授权策略和审批流程。
- `agent_harness/context/`: 上下文选择、预算、压缩和 artifact 管理。
- `agent_harness/storage/`: JSONL 事件、SQLite 索引、checkpoint 和 schema 迁移。
- `agent_harness/telemetry/`: 日志、trace、指标、token、费用和延迟统计。
- `agent_harness/cli/`: 命令行入口、参数解析和交互展示。

核心层依赖内部领域类型。提供商、存储、遥测和 CLI 通过接口依赖核心层，第三方 SDK 对象在适配器边界完成转换。

## 风格与类型

- 遵循 PEP 8、PEP 257 和项目 Ruff 配置，格式以自动化工具结果为准。
- 所有公开函数、方法和类声明完整类型，内部复杂逻辑同样提供类型。
- 公共模块、类、函数和方法编写 docstring，说明职责、约束、返回值和领域异常。
- import 按标准库、第三方库和项目模块分组，优先使用绝对导入。
- 函数保持单一职责，复杂分支拆分为具有领域含义的函数或状态迁移。
- 注释解释决策和约束，代码表达执行步骤。

## 领域建模

- 使用 `Protocol` 表达 provider、tool、storage 和 policy 等可替换边界。
- 使用 `dataclass` 表达稳定的内部值对象，使用 Pydantic 模型校验外部输入、配置和 schema。
- 核心状态使用明确类型，动态载荷具有显式 schema 和版本。
- 状态枚举、停止原因、错误码和事件类型保持稳定且可序列化。
- 新增抽象需要至少两个明确使用场景或一个稳定边界需求。

## 异步与资源

- 网络、模型、文件和进程等 I/O 接口优先提供异步实现。
- 异步路径使用支持异步的依赖，阻塞调用通过明确边界隔离。
- 外部调用设置超时并传播取消信号。
- 文件、连接、流、数据库事务和子进程使用上下文管理器管理生命周期。
- 并发任务具有数量和资源预算，错误保留任务身份与上下文。

## 错误处理

- 模块边界将第三方异常转换为领域异常，并使用异常链保留根因。
- 捕获能够处理的具体异常，顶层入口统一产生稳定退出码。
- 错误信息包含动作、对象和恢复建议，并过滤敏感内容。
- retry 仅处理明确的瞬时故障，同时设置最大次数、退避和幂等约束。

## 依赖与配置

- 运行时依赖与开发依赖在 `pyproject.toml` 中分组维护并锁定可复现环境。
- 引入依赖前确认职责、维护状态、许可证、安全记录和标准库方案。
- 每个第三方依赖通过单一适配边界进入核心逻辑。
- 配置具有类型、默认值、校验规则、优先级和对应文档。

## 变更验证

- 新增或修改行为时同步更新对应单元测试。
- provider、storage、CLI 等边界变化同步更新集成测试。
- 路径、权限、输入处理和资源预算变化同步更新安全测试。
- Agent 决策轨迹发生变化时同步更新相关评测。
