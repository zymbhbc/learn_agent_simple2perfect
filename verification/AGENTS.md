# 验收证据规则

## 目录职责

- `code/`: 阶段功能验收、测试结果、评测报告、trace、run ID 和产物索引。
- `knowledge/`: 知识自测、概念解释、调用链复述、故障分析和掌握确认。

## 记录要求

- 文件说明验收对象、前置条件、操作步骤、预期结果、实际结果、证据和结论。
- 每项结论能够追溯到代码、测试、评测、运行记录或权威资料。
- 命令注明运行目录、环境和关键版本，结果保留必要的原始输出摘要。
- 功能验收引用 `tests/` 与 `evals/`，自动化断言保留在对应目录。
- 知识验收要求学习者独立解释机制、绘制调用链、预测行为或定位故障。
- 验收结论使用 `passed`、`failed`、`blocked`，并记录确认日期。
